# PDF Comparator

Программа для попиксельного сравнения двух PDF-файлов. Различающиеся пиксели выделяются красным цветом в выходном PDF.

## Описание

Программа принимает два PDF-файла, рендерит их страницы в растровые изображения и сравнивает попиксельно. Файл `pdf2` сравнивается с `pdf1`. Результат сохраняется в виде PDF, где:
- Совпадающие пиксели сохраняют цвет из `pdf2`
- Различающиеся пиксели заменяются красным цветом (255, 0, 0)
- Белый фон (значения RGB > 240) игнорируется

## Требования

- Python 3.10+
- PyMuPDF
- Pillow
- numpy
- scipy

## Использование

```bash
./program pdf1.pdf pdf2.pdf
```

### Входные данные

- Два PDF-файла, передаются как аргументы командной строки.

### Выходные данные

- PDF-файл с результатом сравнения (`pdf2` сравнивается с `pdf1`).
- Различающиеся пиксели выделяются красным цветом.
- Результат сохраняется в файл: `pdf1_pdf2_cmp.pdf` (в папке `cmp/`).

## Тесты
- **01** – Сравнение двух PDF, где в `pdf1` нет логотипа, а в `pdf2` он присутствует. 
- **02** – Сравнение двух пустых PDF. 
- **03** –Сравнение двух идентичных PDF, содержащих текст и изображения.
- **04** – Сравнение титульного листа без указания личности и второго листа с указанием личности.
- **05** – Сравнение двух идентичных многостраничных PDF.
- **06** – Сравнение двух многостраничных PDF с различиями.


## Примечание

В тесте **05** возможна ситуация, когда изменение одного символа приводит к смещению всех последующих символов в строке, поскольку каждый символ имеет разную ширину (пропорциональный шрифт). В результате попиксельного сравнения такие смещения будут помечены как различия.
